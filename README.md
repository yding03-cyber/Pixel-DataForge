# Pixel-DataForge

This repository tracks the released datasets for the PixelCaps project.

- [`yding03/PixelCaps`](https://huggingface.co/datasets/yding03/PixelCaps) — the processed split.

The candidate upstream source pool for PixelCaps is in `POOL.md`.

Please open an issue if you have any questions about usage or licensing.
